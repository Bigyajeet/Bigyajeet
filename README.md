## AIML Internship at CTTC (May 26 - July 10)

During my 45-day internship at Central Tool Room & Training Centre (MSME), Government of India, I gained hands-on experience in the following areas:

* **Python Proficiency:** Learned Python and its key libraries for data science, including NumPy, Pandas, Matplotlib, and Seaborn.
* **Data Science Fundamentals:** Gained practical skills in data preprocessing, data visualization, model building, and evaluation.
* **Machine Learning:** Explored both supervised and unsupervised learning techniques.
* **Deep Learning:** Understood the basics of Deep Learning (ANN, CNN) and applied them to practical projects.
* **Real-world Datasets:** Gained experience working with datasets from Kaggle and UCI, solving problems like palindromes and reversing numbers.

I am grateful to Central Tool Room & Training Centre (MSME) Government of India for this wonderful experience and to Dr. Ritu Maity for her constant support and guidance. #cttc #intern #AIML

## Key Projects from my AIML Internship

You can find all my internship projects and code in this dedicated [GitHub repository](https://lnkd.in/gx_pDtQa).

* **Flower Recognition:** Trained a machine learning model to predict flower images using the "Flower Recognition" dataset from Kaggle.
* **Flower Detection:** A project focused on detecting flowers from real-life camera input and image folders. [Project Link](https://lnkd.in/gYKpj4Ut)
* **Face Detection System:** Built a complete face detection system using Deep Learning, from custom data acquisition to model training and evaluation. [Project Link](https://lnkd.in/g8qu_nkH)
* **Game of Thrones Character Similarity:** A machine learning project that uses data processing and visualization to find similarities between Game of Thrones characters. [Project Link](https://lnkd.in/gd_ZSF3t)
* **Cat vs. Dog Image Classification:** Developed a Convolutional Neural Network (CNN) to classify images as either "cat" or "dog," using the "Dogs vs. Cats" dataset from Kaggle. [Project Link](https://lnkd.in/gmeewJhT)

This repository includes mini-projects related to ML, including a Netflix data cleaning and analysis project. I coded daily using Google Colab, Jupyter, Spyder, and VS Code, and regularly pushed my code to GitHub.
